# GeoNLI — Dataset Documentation

Documentation for all datasets used in the project.

## Template

For each dataset, create a separate markdown file documenting:

- **Name**
- **Source URL**
- **License**
- **Task** (captioning / VQA / grounding / detection / segmentation)
- **Format**
- **Total size**
- **Samples actually used**
- **Preprocessing applied**
- **Train / val / test split**
- **Known limitations**

> ⚠️ Never fabricate dataset statistics.
