# GeoNLI — Experiment Logs

Track all model experiments here.

## Template

For each experiment, create a file named `YYYY-MM-DD_experiment-name.md` with:

- **Date**
- **Objective**
- **Model**
- **Dataset**
- **Hardware** (GPU model, VRAM, RAM)
- **Configuration** (input size, batch size, etc.)
- **Task** (captioning / VQA / grounding)
- **Results** (metrics, sample outputs)
- **Observed failures**
- **Conclusions**
- **Next steps**

> ⚠️ Never fabricate results. Record what actually happened.
